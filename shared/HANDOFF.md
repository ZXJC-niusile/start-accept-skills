# Cross-stage handoffs

Load only when passing work between stages or resuming a project.

Use these fields in prose or JSON: `goal`, `inputs` (source and version), `evidence`, `conclusions`, `unknowns`, `outputs`, `next_step`. See [handoff example](handoff.example.json).

For storage layout, write ownership and rechecking after input changes, use the [state contract](../skills/sa-workflow/references/state.md).
