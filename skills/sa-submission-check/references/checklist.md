# Presentation and compliance checklist

Apply only relevant rows and record the input version. For a missing item, state what was searched; an inaccessible supplement is unavailable, not proven absent.

| Surface | Check |
|---|---|
| Language | Recoverable sentence meaning, agreement, stable tense where appropriate, concise phrasing, defined terminology, consistent notation. Do not enforce one universal paragraph length or vocabulary blacklist. |
| Organization | Abstract and conclusion accurately summarize the supplied method/results; section pointers and contribution labels agree. Refer scientific disputes to scientific review. |
| References | Every cited key resolves; entries and in-text style follow the applicable format. Verify source existence and claim support separately when requested; list those not checked. |
| Numerical consistency | Check metric direction, units, denominators, rounding, confidence interval labels, table totals, and cross-surface values. Record exact conflicting locations without guessing which is correct. |
| Figures and tables | Captions, axis labels, legend, units, accessible encoding, legibility at intended size, and agreement with text. Prefer editable/vector charts when suitable; raster source images are valid when resolution is sufficient. |
| Source | Unresolved references, missing assets, malformed markup, duplicate labels, and supported compilation diagnostics. Valid style choices are not syntax errors. |
| Rendered output | Actual page count, clipping, overlap, font embedding when required, readable panels, caption placement, and hidden author information where anonymity applies. Report inspected page range. |
| Submission | Official venue/year/track template, limit counting rules, anonymity, supplementary naming/format, disclosure, and required statements. Record URL/document version and access date. |

Critical findings can include a verified mandatory requirement violation that blocks submission. Major findings materially obstruct reading or create misleading presentation; minor findings are local polish. Do not derive readiness solely from counts.

House-style rules require an actual project/user source. Em-dashes, passive voice, raster figures, and chosen label punctuation are not intrinsically scientific defects. If rules conflict, identify the conflict and controlling current venue requirement; do not silently rewrite.

Output readiness as `ready_for_checked_requirements`, `issues_found`, or `incomplete_checks`, with any unassessed requirement explicit. Passing compilation does not imply correctness, visual quality, or scientific acceptance.
