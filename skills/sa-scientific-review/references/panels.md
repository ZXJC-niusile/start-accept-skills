# Optional review perspectives

Choose only useful lenses: technical correctness, evaluation, closest prior work, practical relevance, or strongest counterargument. State each role's question, input versions, tools allowed, and output ownership. Use separate outputs and one synthesis owner; do not make workers write the same ledger.

Where fresh invocations exist, keep peer findings hidden until each initial report is complete. Otherwise disclose that the perspectives share context. Record actual model/tool execution and unavailable checks; roles and multiple calls do not prove independent errors or calibrated accuracy.

Merge duplicates without counting repeated phrasing as stronger evidence. For every critical/major concern, retain its source, evidence, defense, and disposition. Disagreement can remain contested; majority votes alone cannot settle a factual error. Any new synthesis finding requires its own evidence and must be identified as new.

Give a simulated overall recommendation only if useful or requested, grounded in the stated target/rubric. Missing venue criteria prevent venue-specific claims, not a general scientific assessment. No acceptance probabilities or claims of calibration without a separate validated evaluation.
