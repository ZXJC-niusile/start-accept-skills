# Literature card

Use for reusable notes or multiple-paper comparison; omit irrelevant fields in a short explanation.

| Field | Record |
|---|---|
| Identity | Title, authors, source URL/file, version/date, accessed sections |
| Question | What problem and setting the work addresses |
| Mechanism | Inputs, outputs, assumptions, and essential method steps |
| Evidence | Claim; paper section/table/theorem; reported result and its scope |
| Comparability | Dataset/version, protocol, resources, units, denominator |
| Limits | Author-reported limits; separately labeled reader inferences |
| Unresolved | Missing appendix, inaccessible code, unclear definition, unverified reference |
| Next use | A question for selection/design or source material for writing |

A collection adds the search date, queries, inclusion/exclusion rationale, and a comparison table. Do not equate an empty search result with proof that a research gap is novel.
