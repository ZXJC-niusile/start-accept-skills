# 发布与维护

0.1.3 已作为公开预览发布于 [GitHub](https://github.com/ZXJC-niusile/start-accept-skills/releases/tag/v0.1.3)。本地安装记录见 [宿主验收](HOST_ACCEPTANCE.md)。仓库 main 上的文档可继续更新；已发布 ZIP 和校验值保留对应版本，不随文档整理覆盖。

默认通过克隆仓库安装。ZIP 用于固定版本下载、离线保存或回退；SHA-256 用于完整性核对，均非安装必需。

## 构建

在包根目录运行：

```text
python scripts/build_release.py
```

输出到新的 `dist/start-accept-skills-0.1.3-preview/`：ZIP、SHA-256 和构建记录。构建使用白名单，保留完整技能、公共资源、脚本、公开文档与来源记录。自动检查包内 Markdown 引用、11 个技能和已知本地路径泄露；拒绝覆盖同名构建。需要再次构建时使用 `--output` 指向新的目录。

原始 evals/、tests/、缓存、开发轨迹和执行快照保留在本地，不进入 ZIP。打包检查不是通用敏感信息扫描，也不是宿主安装验证。不要直接把整个开发文件夹压缩上传。
